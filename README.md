# Hiring LLM audit results

Public research companion: https://xinyangwuethz.github.io/hiring-audit-results/

GitHub Pages serves the `main` branch root. Static HTML, CSS and JavaScript;
no third-party frontend dependencies or analytics.

The website includes measured hire-rate curves, per-seed intervals, residual
case overlap controls, mechanism results, benchmarking scopes and downloads.
The results are exploratory development-benchmark findings.

## Update

Edit the site files in this repository. If aggregate CSVs change, regenerate
`results.js` with `python3 build_data.py`. Keep `poster.pdf` synchronized with
the scientific repository's `poster/latex/main.pdf`. Push to `main` to publish.
